# 🧪 Lab DevOps

> Meu laboratório pessoal para aprender, testar e colocar em prática conceitos de **DevOps, Cloud, Linux, automação e infraestrutura**.

Este repositório é onde vou documentar minha jornada construindo e evoluindo meu próprio **Homelab**.

A ideia é transformar um **Raspberry Pi 4** em um pequeno ambiente de laboratório, simulando situações e tecnologias que eu encontraria em ambientes reais de infraestrutura e desenvolvimento.

## 🎯 Objetivo

Mais do que simplesmente instalar ferramentas, quero usar este laboratório para **entender como as coisas funcionam na prática**.

Aqui vou testar, quebrar, corrigir e documentar experiências envolvendo:

* 🐧 Linux
* 🐳 Docker
* 🔄 CI/CD
* ☁️ Cloud
* 🌐 Redes
* 🔐 Segurança
* ⚙️ Automação
* 📦 Containers
* 🏗️ Infrastructure as Code
* 📊 Monitoramento
* 🖥️ Servidores
* 🧩 Kubernetes
* 🐙 Git & GitHub

## 🏠 O Homelab

O coração do laboratório é um **Raspberry Pi 4**, que estou utilizando como um pequeno servidor para meus experimentos.

A ideia é ir evoluindo a infraestrutura aos poucos e transformar o Raspberry Pi em um ambiente cada vez mais próximo de um cenário real.
